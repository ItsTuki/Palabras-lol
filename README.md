# Palabras-lol

Pequeño diccionario de consola en Python con jerga de internet. Escribes una palabra que no entiendes y el programa te dice qué significa.

## Palabras incluidas

| Palabra | Significado |
|---|---|
| CRINGE | Algo excepcionalmente raro o embarazoso |
| LOL | Una respuesta común a algo gracioso |
| ROFL | Una respuesta a una broma |
| SHEESH | Ligera desaprobación |
| CREEPY | Aterrador, siniestro |
| AGGRO | Ponerse agresivo/enojado |

## Uso

Solo necesita Python 3.

```bash
python main.py
```

Puedes consultar hasta 5 palabras por ejecución. Hay que escribirlas en **mayúsculas**, tal como aparecen en la tabla.

Para agregar palabras nuevas, edita el diccionario `meme_dict` al inicio de `main.py`.
